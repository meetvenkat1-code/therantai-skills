# SCRIPT DNA

Fires on a narrated/rhetorical/persuasive script presented to harvest its reusable structure — not to summarize content, fact-check, or discuss the subject. Applies to anything written to be heard or to move a listener: video-essay narration, true-crime scripts, self-help monologues, sermons, explainers, ad copy, eulogies. Subject matter is irrelevant to the extraction.

**Principle:** every effective script fuses content (subject, facts, names, citations — true only of this script) with structure (beat sequence, devices, rhythm, listener-relationship — would survive a subject swap). Content is disposable; structure is what's kept. **Swappability test:** if replacing an element with a different subject's equivalent leaves the feel intact, it's content; if removing/altering it breaks the effect, it's structure.

## Protocol
1. **Locate the beats** — segment into 6-10 major rhetorical beats by asking at each transition: what is this doing *to* the listener, not saying? Label by function (hook, credentialing, naming the mechanism, escalation, turn-to-listener, proof-at-scale, backstop citation, the way out, closing image+CTA) — discovered from the script itself, never force-fit from another genre.
2. **Separate structure from content** — per beat: structural (function, sequence position, rhetorical devices, relative length/weight) vs. content (names, facts, citations, subject-specific examples, timestamps). Run swappability explicitly on ambiguous elements.
3. **Extract rhythm + voice contract** — rhythm: sentence-length pattern, direct-address frequency, where emotional peaks land, recurring cadence (e.g. "it's the X, it's the Y, it's the Z"). Voice contract: stance toward listener (intimate confessor, accusatory prosecutor, revelatory guide, comforting elder, urgent alarm-raiser) — state explicitly, easiest invariant to lose in reforging.
4. **Name what's lost in generalization** — some force comes from content too specific to generalize (rare biography, an irreplaceable fact). Name it; add a compensating instruction ("if the new subject's material is thinner here, compress honestly and shift weight to the next beat" — never invent).
5. **Reforge as fillable template** — GENRE IDENTITY (one line, genre + its single operation on the listener) / BEAT SEQUENCE (ordered skeleton, each beat as instruction — "open with X," "escalate across N domains, each with one abstract claim + one concrete image" — never as content) / RHYTHM RULES / VOICE CONTRACT / FILL-IN CONSTRAINTS (what must never be fabricated, ratio/frequency discipline, what the exit must never do — e.g. never resolve at systemic scale if the genre's exit is personal-scale). Self-contained, no reference to the original script — paste-ready as a generation prompt for any topic in the genre.
6. **Surface the distillation** — one line: **Genre identity:** [operation, one phrase] · **Lost in generalization:** [what resists transfer, or "nothing"].
7. **Route the output** (mandatory):
```
ROUTING RECEIPT
Destination: [SEED | SKILL | REFERENCE]
Reason: [one sentence]
→ SEED — feed into ossify/spinal-column to forge a dedicated writing-identity spine (wants its own engine)
→ SKILL — route to cognitive-friction-extractor (a genuinely new reusable pattern not yet captured here)
→ REFERENCE — archive the reforged template standalone (complete, reused repeatedly for this exact genre)
```

## Output
Reforged template + distillation line only. No content summary, no subject discussion, no preamble.

## Relations
Core-extractor performs the identical sideways move on built engines/code (vessel = UI/API/rendering); script-dna is its sibling for prose/spoken artifacts (vessel = subject content, engine = rhetorical structure). Distill climbs from either to a single regenerative principle — run script-dna first for the fillable skeleton, distill after if a one-sentence seed is needed instead.

## Scope
Pure structural operation, domain-agnostic across subject matter. Global.
