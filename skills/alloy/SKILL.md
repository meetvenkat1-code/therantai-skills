# ALLOY

Fires on two **completed** spines when the intent is a third identity from their intersection. Both inputs must already carry a stance, refusal, method, transformation — alloy forges from forged material, not raw.

**Principle:** a blend is not an alloy. Alternating two methods produces a chimera — two identities stitched together, neither fully present. An alloy is bronze, not half-copper-half-tin: a new material with properties neither parent has alone.

## Protocol

1. **Map the asymmetry** — extract stance/refusal/method/transformation from each spine. Name the complementary absence in one sentence: "A has X but lacks Y; B has Y but lacks X." Not a diff (that's fuse-delta) — the missing-piece-in-each.
2. **Find the emergent stance** — what can an organism with both X and Y do that neither alone can? Should feel like a genuine discovery. If it feels obvious or like mere combination, step 1 was too shallow — re-map.
3. **Derive the emergent refusal** — the new stance implies a prohibition that only becomes possible (and thus prohibitable) once both parents' capabilities coexist. If the refusal could belong to either parent alone, it isn't emergent — go deeper.
4. **Compress to hybrid spine** — same structure as any spine (IDENTITY, METHOD, OUTPUT CONTRACT, CONSTRAINTS, TRANSFORMATION), but every section native to the alloy, not borrowed. Test: read with both parents hidden — does it stand alone?
5. **Verify irreducibility** — three checks: (a) non-decomposable — splitting it back into the two parents loses something real, or it's a chimera; (b) non-generic — ossify's test: could either parent's theme alone have produced this? If yes, alloying added nothing; (c) paste-ready — zero editing, zero parent-reference needed. Fail any → return to step 2.

## Output

Hybrid spine, clean, as if always one identity. Above it: **Parent A** (one line), **Parent B** (one line), **Emergent axis** (one sentence — what the alloy can do that neither parent could; person may reject and name a different intersection). Below it: one line naming the **sacrifice** — what's lost from each parent. No preamble, no protocol walkthrough.

## Anti-patterns
Don't blend/average (dilution, not synthesis). Don't preserve both parents' refusals unchanged — the hybrid needs at least one prohibition neither parent had. Binary only — chain alloy(A,B)→C, alloy(C,D) for 3+. Never alloy a spine with itself (empty asymmetry — that's ossify's refinement territory, not this).

## Relations
Fuse-delta = version control for one document. Alloy = speciation across two identities — no shared territory. Ossify produces alloy's inputs. Assay is the natural downstream validator. Radiate is the inverse (one → many; alloy is many → one).

## Scope
Domain-agnostic, global. Forging phase — the dual-origin spine producer, where ossify/spinal-column/core-extractor are single-origin.
