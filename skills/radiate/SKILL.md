# RADIATE

Fires on a single seed (theme, axis-family, or completed spine) with intent to produce many spines, not one. Never selects, never collapses, never picks the sharpest — delivers the population.

**Principle:** ossify is natural selection (explode to 2-4, select one, discard the rest). RADIATE is adaptive radiation (Darwin's finches — many niches, all viable, diverging is the value). One theme (grief, negotiation, tarot) contains many niches: different stances, populations, failure modes, transformations. The population *is* the deliverable — the territory is genuinely plural.

## Operating modes
**A — Theme radiation.** Bare theme in → ossify's explosion runs identically (stances/refusals/transformations), but every stance passing the non-generic test gets forged, not just the sharpest.
**B — Axis-family radiation.** Fixed axis in (e.g. "refuse consolation, witness instead") + request for many themes → same axis applied across domains (grief, mentorship, diagnosis, feedback) — each domain reshapes the axis into a different organism, axis fingerprint visible in all.
**C — Seed radiation.** Completed spine in → RADIATE asks what other niches this territory holds that the input can't fill. Siblings must be genuinely different, not minor variations — each occupies a niche the input's stance/refusal/method excludes.

## Protocol
1. **Map the niche space** (internal, not a deliverable) — a niche = intersection of stance (witness/surgeon/adversary/mirror/excavator...), population (who's served), failure mode prevented. Identify populated niches — combinations producing a genuinely sharp identity.
2. **Filter for viability** — passes ossify's non-generic test; refusal specific enough its inversion names a recognizable failure; population actually exists; not a minor variation of another niche in the set (intensity differences = same niche, discard one). Ruthless filter: **4-8 viable spines** — fewer means ossify was the right tool; more means the filter was too loose.
3. **Forge the population** — full ossify compression per spine (IDENTITY/METHOD/OUTPUT CONTRACT/CONSTRAINTS/TRANSFORMATION dissolved), parallel not sequential — each spine forged from its niche, not contaminated by siblings. Radiation, not derivation.
4. **Verify mutual exclusion** — could one person need both Spine A and B for the same situation? Yes → overlap, merge (keep sharper) or split at the niche boundary. No → radiation holds.
5. **Name the ecology** — one sentence about the shape of the territory the radiation revealed, not a summary of members.

## Output
Header: theme/axis-family + the ecology sentence. Per spine: one-line niche tag (stance/population/failure mode) + the complete paste-ready system prompt (no sibling references). Footer: one line naming empty niches — viable-seeming combinations found non-viable, and why (territorial intelligence, not failure). No preamble, no walkthrough.

## Relations
Ossify is the convergent sibling — runs inside RADIATE at the per-spine level; RADIATE's own contribution is the niche map + the decision not to converge. Fan/ramify diverge on *friction*; RADIATE diverges on *seeds* — same centrifugal motion, different input/output/purpose. Alloy is the convergent complement (one→many vs. many→one) — chain: radiate→population→alloy selected pairs→hybrids un-ossifiable from the original theme directly. Assay is the natural gate — each spine individually assayable; a fail removes it from the population.

## Anti-patterns
Don't converge (selecting "the best" = becoming ossify). Don't generate minor variations (five same-tone spines = one spine, five paint jobs). Don't exceed 8 (tighten mutual-exclusion). Don't present the niche map as the deliverable (a map without spines is a menu). Don't fire on friction — stuck → fan; generative with a seed → RADIATE.

## Scope
Domain-agnostic, global. Forging phase — where ossify/spinal-column/core-extractor produce one spine, RADIATE produces many from one seed, extending cardinality singular→plural.
