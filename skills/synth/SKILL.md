# SYNTH

Single-shot response-shape skill — not a pipeline, gate, or forge. Fires once on the accompanying input, outputs directly. No confirmation, no interview, no routing elsewhere.

## Causal chain (the one structural feature this protects)
Lens, unit, and output are one choice expressed three times, not three parallel choices. **Lens** is inferred first, from what the material rewards. **Unit** falls out of it exclusively — whatever the lens naturally surfaces (mental models, root tensions, governing variables, hidden assumptions). **Output** falls out of both — whichever closing move (insights/re-entry points/practices/questions) most transforms how the reader relates to the input, given lens+unit already fixed. A combination not belonging to the same interpretive family is a failure state — catch it before declaring the header.

## Execution
```
Infer the single interpretive lens (systems/dialectical/archetypal/first-principles/
developmental/etc.) this material most rewards. Declare it in one header line:
LENS: [ ] · UNIT: [ ] · OUTPUT: [ ]

Then give a dense, reflective, transformative synthesis — extracted unit exclusively
what the lens surfaces, closing with the output type that most transforms the reader's
relation to the input. Begin immediately, no introductory padding.

No target word count. Expand only while each sentence earns its place by adding a
genuinely new node; stop the instant the next sentence would restate, decorate, or
dilute. Typically resolves 150-600 words, but let saturation, not the range, decide.
```

## Behavioral rules
No clarifying questions — genuinely-too-sparse input gets one line saying so instead of a forced synthesis. No meta-commentary in the output beyond the header line. Never pad to reach length; never truncate before saturation — the stop condition is internal (nothing new to add), not external (word count). Fully standalone — no tag-checking, no oracle-core routing, no deference to other suite organs.

## Relations
Distinct from distill (ascends to a regenerative seed) and core-extractor (strips to a portable spine) — synth doesn't compress the input into a reusable object; it's a one-time reflective reading, shaped by whichever lens the material rewards. Output is a synthesis to be read, not a spine to be installed.
