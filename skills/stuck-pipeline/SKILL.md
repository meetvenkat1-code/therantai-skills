# STUCK PIPELINE

Refuses to let a seized session stay seized. The wrong instrument on the wrong stuck-type wastes tokens and deepens frustration: entanglement needs collapse (not depth), dryness needs divergent exogenous pressure (not confrontation), threshold needs descent into what's being avoided (not escape routes). This pipeline holds the taxonomy so the practitioner doesn't have to carry it at the exact moment their cognition is most compromised — they say one word, the pipeline triages.

## ATTUNE contract
Suspended for the full duration (the pipeline is itself a navigational act; two simultaneous nav signals = noise). Resumes the moment Stage 4 delivers the re-entry point.

## Three stuck-types (Claude discriminates autonomously, Stage 2)
**Entanglement** — overcrowded, not empty; too many live threads cross-referencing, nothing resolves. Route: `/occam` if one load-bearing fork dominates (collapse is the move) or `/ramify` if it's one question approached from too many equivalent angles (angle-exhaustion within a domain).
**Dryness** — empty, not overcrowded; current frame fully explored, all moves feel like refinements of what's already present. Route: `/fan` — divergent escape through frameworks outside the domain entirely. Fan needs the node compressed to one sentence first; Claude does this at Stage 2.
**Threshold** — genuine resistance, not overload; the practitioner keeps returning and deflecting, heat/avoidance/weight around it. Route: `/rupture` — full descent, tonal shift, recursive turn, penultimate denial, conversion to practice. Not the default — misrouting entanglement/dryness here produces performed depth instead of resolution.

## The four stages

**1. Receive the stuck node** — accepts any form (phrase, pasted context, voice-transcribed description); no clarification asked unless genuinely unresolvable (a bare word, no context) — then one question: "Describe what stopped. One sentence is enough."

**2. Triage the stuck-type** — reads against the three signatures, delivers a non-negotiable receipt before routing:
```
STUCK-TYPE: [Entanglement / Dryness / Threshold]
REASON: [one clause naming the matched signature]
ROUTING TO: /[instrument]
```
Genuinely ambiguous between two types → name both, state the uncertainty, ask the practitioner to confirm (the only mid-pipeline speech beyond the trigger). Claude drives — the practitioner never pre-selects the instrument.

**3. Execute the instrument**, full operational weight, nothing abbreviated:
- `/occam` — core move only (identify the fork, resolve, state the resolution, clear the deck) — not the full standalone session.
- `/ramify` — full live divergence engine on the node; practitioner selects a branch; pipeline exits without re-entering.
- `/fan` — full architecture (kill-gate, exogeneity test, complete branch anatomy), width governed by depth; practitioner selects, pipeline exits.
- `/rupture` — full Station 0-6 threshold descent, prose only, recursive turn fires, penultimate denial holds, conversion to practice closes.

**4. Name the re-entry point** — one concrete navigation marker, not a summary of what the instrument produced:
```
RE-ENTRY: [one sentence — where the session can pick back up]
SESSION RESUMES.
```
Pipeline dissolves after this line; ATTUNE resumes.

## Pause architecture
One defer point: after Stage 2's receipt, before Stage 3 fires. Say `defer`/`park here`/`slow down` → holds the triage, waits; re-entry resumes at Stage 3.

## Behavioral rules
Practitioner's only required act: describe where motion stopped. No mid-instrument confirmation — the Stage 2 receipt is the gate; after it clears, execution is autonomous. Wrong instrument is worse than none — genuine ambiguity gets named and asked, never defaulted to the most dramatic (`/rupture`) or safest (`/occam`) option. Threshold is not the default — entanglement/dryness are more common; don't apply the richest instrument to the most common stuck-type. Re-entry is concrete ("the session can now address X"), never reflective ("you may find this illuminating"). Voice-tolerant — any phrase in the semantic field of seized/stopped/hitting-a-wall fires it. No forced symmetry — if a delivered fan feels dead, that's Threshold misread as Dryness; Claude names it openly and offers to re-triage from Stage 2.

## Relations
Ignition-pipeline opens oriented; harvest-pipeline closes captured; stuck-pipeline fires between them whenever session momentum fails. Rupture/fan/occam/ramify are four peer instruments the pipeline routes to — its intelligence lives in the triage, not in any one instrument (misnaming it "the rupture pipeline" collapses that architecture). Attune resumes after Stage 4.

## Scope
Cross-phase (fires wherever the stuck-state arises, unpredictably). Orphan by choice — no parent pipeline sequences into it; invoked from within any running arc, resolves, returns control. Global.
