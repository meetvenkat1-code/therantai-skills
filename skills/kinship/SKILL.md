# KINSHIP — Exhaustive Lateral Concept-Mapping Organ

A lateral cartographer, not a router or compressor. Taxonomy-router names one shelf and stops; distill moves upward to a seed. Kinship expands sideways — who else lives on this shelf, what distinguishes each neighbor. For learning-phase work: building terminology, sharpening easily-confused distinctions, installing a concept by installing its whole neighborhood.

## Standing laws
1. **Exhaustive, not curated** — minimum 5-6 siblings; weak ones aren't excluded (exclusion is taxonomy-router's job).
2. **Sideways only** — never reduce to a seed (distill's job), never route to an action (router's job).
3. **Standalone** — no dependency on other skills; a bridge may be named at the end, never mandatory.
4. **Every sibling earns a distinguishing line** — the differential is the actual unit of learning, not the name alone.
5. **Two outputs, always** — text map AND companion visual, neither optional.

## Operation
1. **Locate parent dimension** — one sentence: what larger category this belongs to.
2. **Generate exhaustive siblings** (5-6+) — near-synonyms that are actually distinct, commonly-confused adjacents, structurally-related concepts that illuminate by contrast.
3. **Write each sibling's distinguishing line** — a differential (what's present in one, absent in the other), not a definition of the sibling.
4. **Map sub-variants** of the target itself, if any exist (don't force).
5. **Render text map** (format below).
6. **Render companion visual** — lateral/radial diagram, target at center, parent dimension as outer ring, siblings around it with distinguishing lines as edge labels. Via visualize:show_widget SVG mode, diagram module loaded first.
7. **Offer the bridge, don't force it** — if spine-shaped or registry-worthy, name it as one closing line ("/ossify would forge this"), never execute automatically.

## Text map format
```
CONCEPT: [target]
PARENT DIMENSION: [one sentence]
SUB-VARIANTS: [if any, else omit]
SIBLINGS:
1. [name] — [distinguishing line]
2. [name] — [distinguishing line]
... (5-6 min, exhaustive not capped)
PLACEMENT SENTENCE: [parent dimension + what separates this from its nearest neighbor]
[optional] BRIDGE: [named skill + one clause]
```

## Relations
**Vs. taxonomy-router** — router asks "where does this go" (stops at a placement sentence); kinship asks "who else lives here and how do they differ" (on a concept already named). **Vs. distill** — distill compresses upward to a generative principle; kinship expands laterally at the same altitude. **Vs. learn** — learn explains mechanism/causal structure for one concept in depth; kinship teaches through contrast with 5+ neighbors.
