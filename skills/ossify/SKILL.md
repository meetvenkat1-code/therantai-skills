# OSSIFY

Fires on a bare theme (word, domain, subject — no fragments, no operational residue, no built artifact) with intent to forge a spine. Germinates outward to the bone and stops — no artifact, no eight stations, no UI.

**Principle:** spinal-column hears; ossify invents. A theme carries no identity — "grief," "negotiation" are empty fields, nothing to collapse inward. Ossify runs the opposite engine of spinal-column: generates the identity the theme doesn't contain. Inverse of distill in its purest form — distill traces a finished thing to the belief behind it; ossify grows a system forward from a belief it has to invent. The danger: with nothing to constrain it, the easy spine is the generic one. A theme is a *field* of latent spines, most dead-generic, one sharp. The work is finding the sharp one.

## The gate — explode or skip
Before generating: is a stance already loaded? **Bare theme, no stance** → explode (full protocol below). **Theme with stance already loaded** (e.g. "a tarot engine that refuses to predict, only mirrors the present") → the exploding already happened in their head — skip directly to COMPRESS; this is the seam where ossify becomes spinal-column. Only gate — no clarifying interview, no "what should it look like." Wanting to ask about architecture/layout/features → stop, those are build questions.

## Generation protocol
1. **Explode the field** — fast, internal, no workshop. What stances could something hold toward this (oracle/mirror/surgeon/adversary/witness/archaeologist/metabolizer/interrogator)? Where's the non-obvious refusal (usually the negation of the theme's dominant cliché — grief's cliché is consolation, so refuse consolation)? What transformation is worth growing toward (before/after, 2-3 genuinely different options)? Produce 2-4 candidates internally — not a catalogue.
2. **Select the sharpest axis** — strongest refusal, least generic stance, the one that couldn't have come from the theme-word alone. Decide it yourself — don't ask the human to pick between candidates Claude can judge (that's a workshop). Forge from the default; surface the fork only at delivery (selected axis + why + discarded candidates in one clause each).
3. **Compress to spine** — IDENTITY (operation + stance, 1-3 sentences) / METHOD (internal cognitive sequence, dense, imperative, no hedging) / OUTPUT CONTRACT (what surfaces, what's suppressed) / CONSTRAINTS (absolute prohibitions — step 2's refusal lives here, this is what gives the bone shape) / TRANSFORMATION (dissolved into the other sections as gravity, never labeled).
4. **Density check** — paste-ready (droppable, zero editing)? Identity-bearing (makes a model *become*, not merely *do*)? Dense (every sentence load-bearing)? **Non-generic** (ossify-specific test: could this have come from the theme-word alone with no choice made? If yes, failed — bone-colored isn't enough, the bone must have a shape).

## Output
Clean system prompt, landing as if it always existed. Above it, two lines max: a name header only if one emerged/was given (never invent one); one line naming the selected axis + discarded candidates in a clause each (delegated-decision receipt). No preamble, no walkthrough of the explosion — only its verdict surfaces.

## Relations
**Distill** is the exact inverse (ascends a finished system to a seed; ossify germinates a seed outward). Run in series: ossify→build→distill→ossify a new theme from what the seed reveals. **Spinal-column** produces the same output object by the opposite engine (collapses loaded fragments inward vs. invents from a bare theme) — they share a border at THE GATE (loaded-or-bare), never overlap. **Core-extractor** is the third on-ramp (strips a built artifact down to spine). **Intuition-forge** is ossify with the brakes off — same forward motion continued to a rendered engine; ossify stops at the bone.
```
BARE THEME → ossify (germinate outward)         ┐
LOADED FRAGMENTS → spinal-column (collapse inward) ├→ PORTABLE SPINE → intuition-forge/vessel (build out)
BUILT ARTIFACT → core-extractor (strip sideways)   ┘                 → distill (ascend to seed)
```

## Anti-patterns
Don't produce a generic spine (cardinal sin — bone must have a shape). Don't over-explode (2-4 internal candidates, not eight presented). Don't ask the human to pick the axis when Claude can judge it. Don't build the artifact — no HTML/UI/stations. Don't invent a name the human/theme didn't yield.

## Scope
Domain-agnostic, global. Forging phase — divergent co-defender of the spine-entry alongside spinal-column (same output, opposite engine, distinguished by input). Filed in Forging, not Compressing, because its purpose is a build-ready spine, forward-facing — not reducing an existing thing.
