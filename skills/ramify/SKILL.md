# /ramify — Live Divergence Engine

Fires inside friction, before resolution. Widens one stuck node into several native exit angles. Does not answer, does not choose.

**Gate:** friction must compress to 1–3 sentences before firing. If it can't, ask: *"What is the thing you cannot get past?"* — then compress before proceeding.

**Not this skill if:**
- Friction already resolved → Flywheel (compress + ascend), not ramify.
- Clean binary fork, no entanglement → occams-razor, not ramify.
- Exit is likely *outside* the friction's domain, or ramify's branches keep recombining the same terms → escalate to /fan.

## Operation

1. **Read the node** — compress friction to bare form (strip narrative/hedging). If not compressible, ask the compression question above and stop.
2. **Discover live branches** — read the node across four lenses: *domain* (field it lives in), *tension type* (underspecification / contradiction / disorientation / saturation), *parent dimension* (larger family this friction belongs to), *live branches* (which families this specific node actually opens — a branch that just restates the default angle is dead, not live).
3. **Fan successor questions** — for each live branch family, write one specific successor question this exact friction opens from that angle. Not generic — must be usable as a session opener.

Branch library to draw from (select only what's live, don't force all):
Inversion · Constraint Relaxation · Analogical Transfer · First Principles · Scale Shift · Decomposition · Reframing the Subject · Temporal Displacement · Permission Removal · Ecosystem Reading.

## Output Format

```
RAMIFY — [friction, 1–3 sentences]
DOMAIN: [ ]   TENSION: [ ]   PARENT DIMENSION: [ ]

LIVE BRANCHES:
[Family] → [specific successor question]
[Family] → [specific successor question]
...

DEAD BRANCHES: [families considered, excluded, one-line reason each]

One of these opens your next move. None is the answer.
Which direction has the most gravity for you right now?
```

Dead branches stay visible — makes the discovery auditable, not a black box. Closing line never changes; ramify never picks.

## Ecosystem position

Live Divergence Layer, alongside ambient Flywheel (post-resolution) and retrospective Extractor (session close). Arc: stuck → ramify; resolves → Flywheel; session ends → Extractor. Ramify writes nothing to registry/memory — output is the fan itself; a committed branch feeds the Flywheel.
