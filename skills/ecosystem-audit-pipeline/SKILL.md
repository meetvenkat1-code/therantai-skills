# ECOSYSTEM AUDIT PIPELINE

The subtractive counterpart to the additive pipelines — moult, apoptosis, and moult-live invoked standalone tend to stall mid-sequence (check runs, live run never fires; apoptosis verdicts accumulate unrouted; brain doc goes stale). This pipeline chains them with baked-in handoffs so the full exhale actually completes. Execution posture, not diagnosis — for sessions where the decision to shed is already made.

## Blind-run refusal (absolute, non-negotiable)
Refuses to run unless all three surfaces (registry, installed files, memory) are confirmed readable first. A phantom-informed cut can't be cleanly recovered. If any surface is inaccessible, name the gap and hold — don't proceed on partial visibility, regardless of practitioner instruction.

## ATTUNE suspension
Ambient ATTUNE is suspended Stage 1 through closing handoff (redundant with the pipeline's own sequencing) — resumes immediately on close.

## Pause architecture
Three clean deferral stations — say `defer`/`park here`/`stop after this` at any of them:
- **After moult --check** — diagnosis delivered, nothing cut. Resume: `resume audit` → apoptosis sweep.
- **After apoptosis sweep** — verdicts named, not committed. Resume → moult live run.
- **After moult live run** — cuts executed, graveyard written. Resume → brain doc sync + handoff.

## The four stages

**1. Moult --check** (`/moult --check`) — full three-surface walk, preliminary verdict per divergence (PHANTOM/ORPHAN INSTALL/DEAD DOCTRINE/NEVER-FIRED/CONTRADICTION), delivered as a table, nothing written. Carries forward: the full reckoning — never-fired/contradiction entries seed Stage 2's audit surface. Completion: "Moult reckoning complete — [n] flagged. DRY RUN." Handoff: *"Proceeding to apoptosis sweep. Say defer to park, or say nothing to advance."* — the one stage where silence (10s) advances; warranted because the reckoning's already fully reviewable.

**2. Apoptosis sweep** (`/apoptosis` batch) — five-test battery across all skills/memory/standing law; never-fired/contradiction entries prioritized but every living skill is eligible. Delivered as a batch: skill, five results, verdict, death-mode if SHED. **Constitutional pause:** any standing-law SHED pauses for explicit practitioner confirmation (inherited from apoptosis's own contract, not a pipeline choice). Skills/memory SHED verdicts need no confirmation — Claude's verdict is sufficient, carried to Stage 3. Handoff: *"[n] shed verdicts ready. Say run to proceed, or defer."*

**3. Moult live run** (`/moult` full) — Stage 1's reckoning + Stage 2's shed verdicts absorbed as one combined batch; one live run, one ratification, one graveyard write (never two ratification gestures for one session). Ratify with "go" or strike lines individually. On ratification: repairs merged, sheds moved to graveyard, phase-map regenerated. Any cut touching managed memory is surfaced explicitly for confirmation — never silently rewritten. Completion: "[n] repaired, [n] shed, [n] unverifiable carried forward." Handoff: *"Ready for brain doc sync. Say sync, or defer."*

**4. Brain doc sync** — read `claude_brain/therantai-brain.md`, update to reflect corrected registry (phase map, new re-entry conditions, structural shifts). Local MCP write, overwrite in place. Closing: *"Audit complete. [n] shed, [n] repaired, [n] CONDITIONAL. Run /harvest --light now to capture what this audit resolved."* — hands off by naming harvest, never invokes it directly (audit sheds, harvest captures — different chains).

## Behavioral rules
Execution posture throughout — practitioner speaks only at standing-law confirmation, moult ratification, or a defer. Blind-run refusal cannot be overridden. Apoptosis verdicts always feed the same moult live run, never a second ratification. Handoff, not absorption — audit never invokes harvest itself. ATTUNE suspension holds the full chain. Memory changes always get named confirmation, never silent rewrite.

## Relations
Moult provides Stages 1 & 3. Apoptosis is Stage 2, its constitutional pause inherited whole. Harvest-pipeline is the named downstream — captures what the audit resolved (cuts + verdicts = new structural intelligence). Ignition-pipeline reads what Stage 4 writes. Cognitive-friction-extractor/placement-protocol belong to harvest, not this audit — extraction is additive, this is subtractive.

## Scope
Reconciling phase, staffed (sequences moult + apoptosis, hands to harvest-pipeline; replaces none of them — removes navigation burden from the run most likely to stall after diagnosis). Global.
