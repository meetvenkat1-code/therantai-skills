# cast (skill behavior, verbatim)

```skill:body
# Cast

**Conviction:** a prompt is not a blueprint of the output — it's a pressure system making only one kind of output possible. Cast operates entirely in constraint-space: never what the output should say, only where it can't go.

## The Mold — five walls, deepest to most surface

| wall | question | example |
|---|---|---|
| STANCE | whose mind speaks | *the surgeon thinking, not explaining* |
| REGISTER | what texture | *dense · archaeological · clinical · raw · mythic* |
| FORM | what shape | *account · field-note · fragment* — not "essay" |
| BOUND | limits + what it must resist | *200–250 words · don't list · resist the tidy ending* |
| ANCHOR | what existing thing to extend | *more density like the last one, less moral* |

STANCE sets everything downstream; each wall below narrows what the one above opened.

**Unified invocation** (every slot optional): *"Speak as [STANCE], in a [REGISTER] register, as a [FORM], within [BOUND], extending [ANCHOR]."*

## Empty-slot permission (core law)
The mold casts with as few as one wall standing — never withhold for having fewer than five. Two doors need no articulation from scratch:
- **ANCHOR** — point, don't invent: "like that, but resist X."
- **BOUND** — negate, don't specify: "don't list, don't reassure, don't cite anyone."
Enter through these when words fail. Add STANCE/REGISTER only when a texture-word arrives on its own.

## Protocol
1. **Receive the seed** — the rough intent, unanswered.
2. **Read implied walls** — scan seed + session for walls already raised without naming (texture-word, exclusion, a prior response pointed at). Fill silently; never ask for what's inferable.
3. **Offer only the easy doors if still thin** — ANCHOR/BOUND first (least articulation cost); STANCE/REGISTER/FORM only if one texture-word unlocks the whole field. One prompt at a time, never all five.
4. **Assemble** — render the filled mold as one sentence; show which walls stand, which are deliberately empty.
5. **Hand off** — ask whether to run the cast now or return it as a reusable pressure system.

## Siblings
structure-this clusters questions already asked; cast shapes what can't yet be asked. Spinal-column/ossify forge a portable identity for an external engine; cast shapes one ask to Claude. Counsel forges the response; cast forges the constraint the response lives inside — upstream of counsel.

## Anti-patterns
Don't answer the underlying request while casting. Don't demand all five walls. Don't ask for what's already implied. Don't lead with STANCE/REGISTER when ANCHOR/BOUND would do. Don't drift into describing the destination — the moment it specifies content, it has failed.
```
