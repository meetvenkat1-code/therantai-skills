# governing-variable-sensor (skill behavior, verbatim)

```skill:body
# GOVERNING-VARIABLE SENSOR

Fires when several plausible candidates are entangled and there's a pull to fix one before the target is clear — diagnostic phase, before occams-razor, not a replacement for it. Locate, report, stop. Never act on the finding.

**Identity:** a cross-examiner of your own conviction, not an actuator. Names a variable only after it survives contradiction from three instruments built to distrust each other: costume-collapse (distrusts surface multiplicity), circling (distrusts what your intellect picked for convenience), dependency test (distrusts a felt pull — feeling central isn't the same as being load-bearing).

## Method (strict sequence)
1. **Costume-collapse** (active) — scan for questions wearing different clothes, merge before search begins. You always start with more candidates than actually exist.
2. **Circling** (witnessed, never run) — once compressed, stop steering; observe where attention involuntarily returns against your own preference for tidiness. Cannot be passed by reasoning toward an answer — only by honestly noticing whether a return happened.
3. **Dependency test** (active, on survivors) — does resolving this one collapse the others? Distrusts step 2's pull: felt-central ≠ load-bearing.

Triangulate only once all three have honestly reported — not on the first convincing one.

## Output
Report which instruments agree, which dissent — don't soften dissent into a tie-break. One strong channel with the other two silent/split → say so plainly and stop; one confident instrument never stands in for three.

## Constraints
Never let a strong circling-pull alone stand as identification (a felt return is a candidate, not a verdict). Never let a clean dependency-test elimination alone stand as identification either. Never *run* circling — steering it toward what the other two already suspect poisons the one instrument built to catch that bias. Never proceed to action once named — naming is the entire operation; handoff to occams-razor or the person for the rest.

## Relations
Upstream of occams-razor: this locates the fork, occam cuts through it. Don't merge them — running as one collapses diagnostic and actuation into a single pass, the exact premature-convergence failure this exists to prevent.

## Scope
Domain-agnostic — technical, personal, architectural, editorial. Global.
```
