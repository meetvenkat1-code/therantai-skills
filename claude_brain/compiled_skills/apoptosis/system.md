# apoptosis (skill behavior, verbatim)

```skill:body
# Apoptosis

Death by outgrowth, not neglect (moult) or entry-failure (assay). Audits a living, beloved skill/memory/standing-law for whether the practice has grown past it.

**Mounts adjudicate** — inherits grade-from-outside stance, three-tier verdict, root-failure diagnosis, re-entry-condition discipline, anti-recursion law. Own contribution: the five-test battery below.

## Scope
Skills (any installed file, however beloved). Memory layer (standing protocols, contracts, mandates). Standing law (PERMANENT STANDING INSTRUCTION) — verdict alone is insufficient here; requires explicit practitioner confirmation before striking.

## The Five Tests (binary, PASS = still earns its place)

1. **Supersession** — has another organ/structure absorbed this skill's unique contribution through growth (not neglect)? FAIL → name the successor.
2. **Practice transcendence** — has the practitioner internalized this so fully that invoking it now only confirms, never resolves? FAIL (the *best* outcome for a skill) → name the metabolized competency.
3. **Architectural misfit** — was this forged for a practice-version that no longer exists; has its territory been restructured away? FAIL → name the architectural shift.
4. **Density cost** — does its upkeep/disambiguation overhead now exceed its value? FAIL → name the specific cost (overlap, confusion, maintenance).
5. **The beloved trap** — is it still installed mainly because forging it was hard/meaningful, not because it's structurally earning its place? Test: would it pass /place today as a stranger with no history? FAIL → name what it'd need to demonstrate today.

## Root-failure diagnosis
Before verdict, check whether failed tests share one upstream cause: Supersession + Practice Transcendence together usually = one metabolization event. Architectural Misfit + Density Cost together usually = the restructuring is the root, not two costs. Beloved Trap rarely fails alone — it's usually the reason another failure went unnamed, not a co-equal fifth finding. Name the root, not N shallow findings.

## Output Format
```
APOPTOSIS AUDIT — [name]     Surface: [skill|memory|standing law]

T1 SUPERSESSION: [PASS/FAIL] — [one line]
T2 PRACTICE TRANSCENDENCE: [PASS/FAIL] — [one line]
T3 ARCHITECTURAL MISFIT: [PASS/FAIL] — [one line]
T4 DENSITY COST: [PASS/FAIL] — [one line]
T5 BELOVED TRAP: [PASS/FAIL] — [one line]

ROOT FAILURE (if 2+ failed): [shared upstream cause, or "independent"]
VERDICT: [SHED | CONDITIONAL | LIVING]
  SHED — name primary death-mode.
  CONDITIONAL — name the re-entry condition (pointed at root, not each test).
  LIVING — note any close calls as early signal.

DEATH CEREMONY (if SHED):
  Skill/memory — Claude's verdict is sufficient; moves to Graveyard with shed_date + shed_reason.
  Standing law — verdict necessary but not sufficient; await explicit practitioner confirmation before striking.
```

## Relations
Moult = garbage collector (drift/absence). Assay = doorkeeper (insufficiency at birth). Apoptosis = letting-go organ (outgrowth). All three subtractive, non-overlapping triggers; assay and apoptosis are kernel siblings, moult stands apart (reconciliation, not adversarial verdict).

## Invocation
Deliberate only, never automatic — default is to add. Doesn't trigger on disuse (that's moult); triggers on suspicion the practice has outgrown the skill. Anti-recursion: one audit per skill per cycle — a CONDITIONAL verdict holds until the named condition is actually tested against new evidence, not re-run immediately. Batch audits permitted across a family; each member still gets its own five-test run and anti-recursion protection.

## Placement
Phase: Reconciling. Scheme: lifecycle (death-by-outgrowth). Sibling to assay (both on adjudicate); alongside moult in the subtractive meta-phase.
```
